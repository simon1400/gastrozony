## 2. `design/assets/` — вырезанные ассеты

В XD specs справа есть панель, откуда дизайнер может отдать assets.
Если кнопки скачивания нет — попроси у Dana исходник `.xd` или экспорт ассетов.

- [ ] **Логотип Gastrozony** — SVG (жёлтый круг-иконка отдельно + логотип целиком,
      версия для чёрного фона и для белого)
- [ ] **Еда, PNG с прозрачностью, большие (≥1500px по длинной стороне):**
      бургер большой, бургер малый, пицца большая, пицца малая, фри (россыпь),
      + всё остальное, что есть в макете
- [ ] **Логотипы клиентов** (SVG или PNG на прозрачном):
      Pilsner Fest, Burger Arena, Burger Street Festival, HIP HOP ŽIJE, + остальные

      (белый→серый, серый→белый, белый→чёрный, чёрный→жёлтый — 4+ штуки).
      Это критично: на глаз воспроизвести кривую невозможно.

- [ ] **Жёлтое пятно (flek)** — если это картинка, а не CSS-эффект: PNG/SVG.

## Альтернатива: снять самому

Если выгрузка из XD затруднена — на следующей сессии могу открыть ссылку через
Playwright MCP, пройти по артбордам и наснимать скриншоты автоматически.
Так соберём `design/screens/` и tokens (цвета читаются из specs-панели),
**но вырезанные PNG еды и SVG волн так не достать** — их всё равно нужно
экспортировать из XD или получить исходник от Dana.

## Приоритет

Без чего не начать вёрстку HP: **волны (SVG), PNG еды, логотип, шрифт, цвета.**
Всё остальное можно добирать по ходу.
