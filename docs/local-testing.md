# Как запустить и протестировать локально

Пошагово, для проверки перед показом заказчику. Всё выполняется в `D:\gastrozony`.
Найденные проблемы записывайте списком — в новой сессии пойдём по ним.

---

## 1. Что должно быть установлено

- **Node.js 20+** (`node -v`)
- **PostgreSQL 17** — служба запущена, база `gastrozony` уже создана (пользователь `gastrozony`)
- Терминал: PowerShell или Git Bash

Проверка, что база на месте:
```powershell
& "C:\Program Files\PostgreSQL\17\bin\psql.exe" -U gastrozony -d gastrozony -c "\dt" | Select-Object -First 5
```
Спросит пароль — он лежит в `strapi\.env` (строка `DATABASE_PASSWORD`).

---

## 2. Запустить два сервера

Нужны **два отдельных окна терминала** — они работают одновременно.

**Окно 1 — Strapi (CMS), порт 1337:**
```powershell
cd D:\gastrozony\strapi
npm run develop
```
Готово, когда появится `Welcome back!` и адрес `http://localhost:1337/admin`.
Первый запуск после обновлений может занять 1–2 минуты (пересборка админки).

**Окно 2 — сайт (Next.js), порт 3000:**
```powershell
cd D:\gastrozony\client
npm run dev
```
Готово, когда появится `Ready in ...`.

> Если порт занят — значит сервер уже запущен в другом окне, второй раз не запускайте.
> Остановить: `Ctrl+C` в соответствующем окне.

---

## 3. Открыть

| Что | Адрес | Логин |
|---|---|---|
| Сайт | http://localhost:3000 | — |
| Админка CMS | http://localhost:1337/admin | ваш админ Strapi |
| Таблица заявок | http://localhost:3000/sprava/prihlasky | логин/пароль из `client\.env.local` (`ADMIN_USER`, `ADMIN_PASS`) |

---

## 4. Что проверить — по пунктам

Идите сверху вниз, отмечайте, что не так.

### 4.1 Главная — http://localhost:3000
- [ ] Экран целиком: шапка, заголовок с жёлтыми пятнами, еда, кнопки, статистика
- [ ] Секция «Dodáme jídlo i nápoje» — три пронумерованные карточки, теги «Stavíme pro:»
- [ ] Логотипы клиентов
- [ ] Тёмная секция «Aktuální akce» — три карточки акций
- [ ] Жёлтый блок newsletteru и патичка
- [ ] **Сузьте окно** до ширины телефона — ничего не уезжает вбок, меню превращается в бургер

### 4.2 Акции
- [ ] http://localhost:3000/akce — три вкладки: `Aktuální`, `Připravujeme`, `Proběhlé`, переключаются
- [ ] Клик по карточке → детальная страница: обложка, дата, место, текст, галерея (клик по фото = увеличение)
- [ ] Кнопка «Přihlásit se na tuto akci» ведёт на форму с уже выбранной акцией

### 4.3 Форма заявки — http://localhost:3000/prihlaska
- [ ] Отправить пустую форму → поля подсвечиваются по-чешски
- [ ] Ввести кривой e-mail (`abc@`) → ошибка под полем
- [ ] Заполнить целиком, приложить фото или PDF, отправить → «Děkujeme!» без перезагрузки страницы
- [ ] Заявка появилась в http://localhost:3000/sprava/prihlasky
- [ ] Там же «Exportovat CSV» → файл открывается в Excel, чешские буквы целые

> Письма локально **не отправляются** (нет ключа Resend) — это нормально.
> В окне Next видно строку `[mailer] RESEND_API_KEY není nastavený…` — значит код дошёл до отправки.

### 4.4 Остальные страницы
- [ ] http://localhost:3000/novinky — список статей, клик → статья, внизу «Další články»
- [ ] http://localhost:3000/kontakt — контакты, команда
- [ ] http://localhost:3000/info, `/pro-prodejce`, `/pro-poradatele` — тексты и блоки
- [ ] http://localhost:3000/cokoliv-neexistuje → красивая страница 404

### 4.5 Cookies
- [ ] В приватном окне браузера внизу появляется лишта cookies
- [ ] «Nastavení» → переключатель аналитики; «Přijmout vše» → лишта исчезает и не возвращается после F5
- [ ] Внизу патички ссылка «Nastavení cookies» открывает выбор заново

> Локально аналитика не грузится — нет переменной. Если хотите проверить и её:
> `NEXT_PUBLIC_GTM_ID=GTM-K6H6424Z npm run dev` (в Git Bash) — после согласия в Network появится `gtm.js`.

### 4.6 Админка — http://localhost:1337/admin
Это то, что увидит заказчик. Инструкция для него — `docs/admin-guide.md` (по-чешски).
- [ ] `Content Manager → Akce` — поменять заголовок акции, **Save** и **Publish** → изменение видно на сайте (обновить страницу)
- [ ] `Single Types → Homepage` — поменять текст в hero → видно на главной
- [ ] `Single Types → Stránka přihlášky` — поля `mailSubject`, `mailIntro`, `mailNote` (тексты письма)
- [ ] `Content Manager → Formulář → prodejce` — можно добавить/убрать поле формы, оно появится на `/prihlaska`

> Изменения на сайте появляются **до 60 секунд** (кеш) — если не видно сразу, обновите через минуту.

## 5. Частые заминки

| Симптом | Что делать |
|---|---|
| Страницы висят или 500 после долгой работы | `Ctrl+C` в окне Next и заново `npm run dev` (известная болячка dev-режима) |
| `next dev` ругается на порт 3000 | Сервер уже запущен в другом окне |
| Картинки не грузятся | Проверьте, что в `client\.env.local` есть `NEXT_PUBLIC_IMAGEKIT_URL_ENDPOINT` |
| Пусто вместо контента, в консоли ошибки Strapi | Не запущен Strapi (окно 1) или он ещё собирается |
| Нужно вернуть демо-контент | `node scripts\seed.mjs` из `D:\gastrozony` — перезапишет тексты на исходные |

## 6. Тестовый сайт в интернете

То же самое, но уже на сервере — можно показывать заказчику:

- Сайт: **https://gastrozony.hardart.cz**
- Админка: **https://strapi-gastrozony.hardart.cz/admin**
- Заявки: **https://gastrozony.hardart.cz/sprava/prihlasky**

Там своя база (перенесена копия локальной) — правки в локальной админке на тестовый сайт **не попадают**,
и наоборот. Код приезжает автоматически: `git push` в `main` → GitHub Actions → сборка и перезапуск на сервере.

---

## 7. Как записывать найденное

Чтобы в новой сессии сразу браться за дело, по каждой проблеме нужно:
1. **адрес страницы** (`/akce/mint-market-food-festival`),
2. **что не так** («бейдж съезжает на мобильном», «дата в формате 10.09.2026 вместо 10. 9. 2026»),
3. **ширина окна**, если дело в вёрстке (десктоп / планшет / телефон),
4. скриншот, если проще показать.

Список можно просто вставить в новую сессию — начнём с него.
